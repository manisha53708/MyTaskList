### Deskripsi Aplikasi
Aplikasi MyTaskList merupakan platform mobile storefront yang dikembangkan khusus untuk TechGears Store menggunakan framework React Native dan ekosistem Expo. Aplikasi ini dirancang untuk menampilkan berbagai produk perangkat keras dan aksesori teknologi dengan antarmuka yang modern dan responsif. Fokus utama pengembangan ini adalah pada implementasi UI/UX menggunakan JSX styling serta manajemen state yang efisien dalam lingkungan mobile.

### Fitur yang Diimplementasikan
- [x] Integrasi UI dengan React Native & Expo
- [x] Implementasi Layout Manager untuk tampilan katalog produk
- [x] Navigasi antar komponen toko (TechGears Store Storefront)
- [x] Manajemen aset gambar dan screenshot aplikasi
- [x] Penggunaan fitur-fitur dasar mobile UI components
